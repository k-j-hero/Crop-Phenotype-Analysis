# Crop Phenotype Analysis

## 목적
공개 작물 데이터를 이용해 재현 가능한 고추 표현형 분석을 수행한다.

## 첫 연구 질문
2000년 이후 국가별 고추 수확량은 어떻게 달라졌으며, 그 차이를 해석할 때 무엇을 조심해야 하는가?

## 분석 범위와 단위

- 기간: 2000년부터 FAOSTAT에서 이용 가능한 최신 연도까지
- 원자료 분석 단위: 국가(Area) × 연도(Year) × 품목(Item) × 지표(Element)
- 대상 지표: 수확량(Yield)
- 품목 범위: 생고추와 건고추는 FAOSTAT에서 별도 품목으로 확인하고, 첫 분석에서는 임의로 합치지 않는다.

## 성공 기준
- FAOSTAT 자료의 품목 정의와 수확량 단위를 문서화하고, 국가별·연도별 수확량 변화를 재현 가능한 코드와 그림으로 제시한다.
- 분석에 사용한 데이터 파일명, 출처 URL, 다운로드 날짜, 품목·지표 필터, 결측값 처리 기준을 README와 PROJECT_LOG에 기록한다.
